ပြီးခဲ့တဲ့ ၂၀၂၅ ခုနှစ်၊ နှစ်စမှာ Website ရေးတာကို သေချာလေ့လာမယ်ဆိုပြီး ဟိုရှာဒီရှာလုပ်ရင်း [Hugo](https://gohugo.io/) ကိုတွေ့ခဲ့တယ်။ Hugo ဟာ အရမ်းမြန်ပြီး Static Stie Generation (SSG) အတွက် ဘာမှပြောစရာမရှိအောင် ကောင်းလွန်းပါတယ်။ အခုဒီကျနော့်ရဲ့ Personal Website ဖြစ်တဲ့ [https://minsoehan.com](https://minsoehan.com) ကိုလည်း Hugo နဲ့ ရေးထားပါတယ်။ သို့သော် Server Site Rendering (SSR) ကိုပါလိုချင်ရင်တော့ တခြား တစ်ခုကို ရှာရပါတယ်။ အဲ့သည့်မှာ [Astro](https://astro.build/) တွေ့တာပါပဲ။ တခြားဟာတွေ သုံးဖူး သိဖူးလို့ ရွေးခဲ့တာမျိုးမဟုတ်ပါဘူး။ Astro ရဲ့ website မှာ "**The web framework for content-driven websites**" ဆိုပြီး ရေးထားလို့ ရွေးခဲ့တာဖြစ်ပါတယ်။ SSR လည်းရမယ်၊ content-driven ဖြစ်လို့ static post တွေလည်း အများကြီး တင်လို့ရမယ်ဆိုတဲ့ အတွေးနဲ့ ရွေးခဲ့တာပါ။ အရွေးမှန်ခဲ့ပါတယ်။

Website တစ်ခုကို တင်ဖို့ အရင်ကလို Hosting ဝယ်ပြီး Wordpress လုပ်ဖို့ဆိုတာက ခေတ်မမီတော့ဘူး ထင်တာပဲ။ ဒါကြောင့် ကိုယ်ဖန်တီးထားတဲ့ website ကိုတင်ဖို့ [Codeberg Pages](https://codeberg.page/) နဲ့ [GitHub Pages](https://docs.github.com/en/pages) တို့ကို စမ်းခဲ့တယ်။ ကောင်းကြပါတယ်။ အဲ့သည့်နောက် Google ရဲ့ [Firebase](https://firebase.google.com/) ကိုလည်း စမ်းခဲ့ဖူးတယ်။ နောက်ဆုံးမှာတော့ [Cloudflare](https://www.cloudflare.com/) ကိုပဲ သုံးဖြစ်ခဲ့တယ်။ အခုချိန်မှာတော့ Cloudflare ရဲ့ [Cloudflare Pages](https://pages.cloudflare.com/) နဲ့ [Workers](https://developers.cloudflare.com/workers/) တွေအပြင် [R2](https://developers.cloudflare.com/r2/) နဲ့ [Zero Trust](https://www.cloudflare.com/sase/products/access/) တို့ဟာ မရှိမဖြစ် သုံးနေရတဲ့ ဝန်ဆောင်မှုတွေ ဖြစ်နေပါပြီ။ [MGMAemp](https://mgmaemp.com/) ကို Astro + Cloudflare နဲ့ တည်ဆောက်ထားတာ ဖြစ်ပြီး R2 နဲ့ Zero Trust ကိုလည်း သုံးထားရပါတယ်။ ဒီနေရာမှာ Astro + Cloudflare အတွဲကို ရွေးချယ်လိုက်မိတဲ့ အဖြစ်ကို အံ့ဩမိတာပါ။

Cloudflare က ၂၀၂၆ ခုနှစ်၊ ဇန်နဝါရီလမှာ Astro ကို ဝယ်လိုက်ပါတယ်။ Cloudflare က [Cloudflare Acquires Astro to Accelerate the Future of High-Performance Web Development](https://www.cloudflare.com/press/press-releases/2026/cloudflare-acquires-astro-to-accelerate-the-future-of-high-performance-web-development/) စာမျက်နှာမှာ ဖော်ပြထားပြီး Astro ကတော့ ၎င်းတို့ရဲ့ Blog စာမျက်နှာ [The Astro Technology Company joins Cloudflare](https://astro.build/blog/joining-cloudflare/) မှာ ဖော်ပြထားပါတယ်။ MGMAemp အတွက် Astro နဲ့ Cloudflare ကိုရွေးခဲ့တာ မှန်သွားခဲ့ပါပြီ။ ပိုကောင်းတဲ့ Cloudflare integration အတွက် **workerd** ပါဝင်လာမှာဖြစ်တဲ့ Astro 6 ထွက်လာမယ့်ရက်ကိုလည်း စောင့်ဆိုင်းနေပါတယ်။ Astro က Astro 6 Beta ကို Blog စာမျက်နှာ [https://astro.build/blog/astro-6-beta/](https://astro.build/blog/astro-6-beta/) မှာ ထုတ်ပြန်ထားပြီဖြစ်ပါတယ်။
